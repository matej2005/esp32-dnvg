## Features

 1. Onscreen menu
    - Changing filter
        - No Effect, Negative, Grayscale, Red Tint, Green Tint, Blue Tint, Sepia
    - Rotation of display
        - 0, 90, 180, 270
    - White balance
    - Restoring setings back
    - Setings are saved, when exiting from menu
    - FPS counter
    
  2. Some debug info on serial
